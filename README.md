# Mazganim

Адаптивный сайт компании по чистке кондиционеров. Vue 3 + Vite, готовый HTML при сборке, Cloudflare Workers Static Assets. Без API, базы данных, серверного рендера на запрос и внешних шрифтов.

## Статус референса

Репозиторий https://github.com/stackofart/mazganim на момент работы (11 сентября 2026) возвращал 404 через GitHub и публичный Git. Его содержимое **не было получено**. Название Mazganim — рабочее имя из URL, перечень услуг и текст — предложенный черновик, а не извлечённые данные компании. Телефон, WhatsApp, города, цены, рейтинги и отзывы не выдуманы. До сверки с исходником сайт имеет `noindex`; форма честно готовит копируемый запрос и не имитирует отправку.

Нужен доступный репозиторий или локальный путь. После получения источника следует сверить услуги и функциональность, заполнить `src/data/company.js`, проверить тексты и выставить `verified: true`. Тогда сборка включит индексацию и микроразметку HVACBusiness.

## Разработка

Node.js 22.12+ (рекомендуется актуальный LTS), npm.

```sh
npm ci
npm run dev
```

`npm run build` собирает клиент, один раз рендерит Vue на этапе сборки, генерирует `dist/index.html`, `robots.txt`, `sitemap.xml`, `404.html` и удаляет промежуточный SSR-код. `npm run check` проверяет подготовку запроса, HTML, микроразметку, локальные ссылки и ресурсы после сборки.

## Запуск на Cloudflare Workers

1. В `src/data/company.js` внесите подтверждённые сведения: `name`, `phone` (E.164), `whatsapp`, `serviceArea`, `verified`.
2. Укажите реальный адрес сайта через `SITE_URL` в `.env` / переменной окружения сборки. Он нужен для canonical, Open Graph и sitemap. По умолчанию используется адрес закрытого предпросмотра Sites. Пересоберите сайт после смены домена.
3. При необходимости измените имя Worker в `wrangler.jsonc`.

```sh
npm run build
npm run check
npm run dev:worker
npx wrangler deploy --dry-run
npx wrangler login
npm run deploy
```

`npm run deploy` проверяет наличие бизнес-данных, пересобирает и публикует статику. Реальная публикация в пользовательский аккаунт Cloudflare не выполнялась. `wrangler.jsonc` использует Workers Static Assets — отдельный `fetch`-обработчик не нужен. Cloudflare раздаёт файлы из `dist`, отсутствующие адреса получают настоящий 404. После первого деплоя назначьте custom domain в панели Cloudflare и пересоберите с ним `SITE_URL`.

Для Git-connected Cloudflare Worker: build command `npm run build`, deploy command `npm run deploy`, build variable `SITE_URL` с адресом вашего домена. Для закрытого предпросмотра через Sites используется `.openai/hosting.json`; от него запуск в собственном Cloudflare-аккаунте не зависит.

## Функциональность

- Описание услуг с доступными диалогами, процесс, факторы стоимости и FAQ.
- Подготовка заявки: тип, 1–10 блоков, город, необязательные имя и комментарий.
- WhatsApp открывает подготовленный текст на **подтверждённый** номер. Посетитель сам отправляет его; бронирование не считается подтверждённым автоматически. При отсутствии номера доступно копирование и показано объяснение.
- Телефонная ссылка появляется при наличии реального номера.
- Мобильное меню, клавиатурная навигация, reduced motion, native share с clipboard fallback.
- Детали компании и содержание вынесены в `src/data/`.

## SEO и продвижение

Полный индексируемый HTML существует до выполнения JavaScript. Один H1, семантические секции, description, canonical, Open Graph / X title и description, sitemap, robots, favicon. Шрифты и изображение локальные; CSS/JS с хешами кешируются год. FAQ-разметка не гарантирует расширенный сниппет Google. Без подтверждённых данных LocalBusiness не публикуется; несуществующие оценки, отзывы и цены отсутствуют.

Поддерживаются `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`: сохраняются только в sessionStorage вкладки; источник и кампания включаются в подготовленное сообщение. Не передавайте персональные данные в UTM. Кнопка «Поделиться» добавляет `utm_source=referral&utm_medium=share`.

`src/lib.js` предоставляет очередь `window.dataLayer` с событиями `lead_start`, `service_view`, `lead_prepared`, `lead_whatsapp_click`, `lead_copy`, `phone_click`, `site_share`. Контактные данные в события не включаются. Это точки подключения, **GA4, GTM и Meta Pixel не установлены**, данные никуда не отправляются. Клик WhatsApp не равен полученной заявке. Для оценки продаж сверяйте кампанию из сообщения с реально полученными обращениями. При подключении внешней аналитики обновите CSP, описание обработки данных и необходимые настройки согласия.

Отдельная картинка для социальных превью не создана; метаданные пока текстовые. Для локального SEO после подтверждения сведений поддерживайте одинаковые название/телефон/географию на сайте и в бизнес-профилях. Не создавайте страницы городов без реального покрытия и самостоятельного полезного содержания.

## Минимальная архитектура

`Посетитель → Cloudflare Static Assets → готовый HTML + CSS + Vue → WhatsApp`

Vue используется для интерактивности; `@vue/server-renderer` выполняется только во время сборки. Персональные данные формы остаются в памяти браузера до явного перехода в WhatsApp. Без CRM нет серверного журнала заявок, автоматических уведомлений и сквозного учёта продаж. Если они понадобятся, можно добавить один Worker endpoint с защитой от спама и HTTP-интеграцией, оставив страницы статическими. Сейчас это сознательно не добавлено.

WebMCP `prepare_cleaning_request` — необязательное улучшение для поддерживающих браузеров. Оно только заполняет видимую форму и готовит сообщение; ничего не отправляет. Обычный сайт не зависит от WebMCP.

## Ресурсы

`public/images/hero.jpg` — декоративная сцена, сгенерированная встроенным ImageGen; не фотография работы компании. Промпт и происхождение в `docs/assets.md`. Golos Text размещён локально под SIL OFL; лицензия — `public/fonts/OFL.txt`.

Актуальная архитектура сверена с [документацией Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) и [настройкой assets](https://developers.cloudflare.com/workers/static-assets/binding/).
