- Measurement ID: `G-4YMWN76B5B` (публичный идентификатор, не секрет).
- Ресурс: `554062305`, веб-поток: `15774966035`.
- Один прямой Google tag. Не добавлять второй сниппет через GTM или Cloudflare.
- Реализация: `src/analytics.js`, интерфейс выбора: `AnalyticsConsent.vue`.

## Согласие и данные

Используется basic consent mode: до разрешения нет загрузки Google и нет очереди действий посетителя. Разрешение включает только `analytics_storage`. `ad_storage`, `ad_user_data`, `ad_personalization` остаются denied; Google Signals и персонализация отключены в конфигурации тега. Выбор хранится 180 дней; такой же предельный срок установлен для GA cookies. Отзыв через настройки в подвале включает `ga-disable`, обновляет consent и удаляет cookies этого потока. Изменение выбора синхронизируется между вкладками.

Имя, телефон, комментарий, Turnstile token и ID заявки не передаются. В событиях разрешены только фиксированные названия и значения параметров. `page_location` содержит только основной домен и путь языка, без query/hash. `page_referrer` содержит только origin. UTM принимаются как ограниченные текстовые метки кампаний; адреса email и телефоноподобные значения отбрасываются. Никогда не помещайте персональные данные в UTM. Параметры рекламных кликов и рекламные функции нужно отдельно проверить при будущем подключении Google Ads.

Локальные и Workers-предпросмотры не отправляют события. Отказ посетителя, блокировщик или сбой сети означают, что действие не попадёт в GA4. Это не мешает отправке самой заявки: база Cloudflare остаётся источником истины по полученным обращениям. GA4 не является журналом гарантированной доставки.

## События

| Событие в GA4 | Когда отправляется |
| --- | --- |
| `page_view`, `session_start`, `first_visit`, `user_engagement` | Стандартные события Google после согласия |
| `scroll` | Стандартная улучшенная статистика прокрутки |
| `booking_click` | Клик по кнопке записи / переходу к контакту |
| `prices_click` | Кнопка стоимости на первом экране |
| `whatsapp_click`, `telegram_click`, `phone_click` | Клик контакта, без номера или URL |
| `form_start` | Первое изменение видимого поля формы после согласия |
| `form_error` | Ошибка: validation, challenge, rate_limit, network или server |
| `generate_lead` | Только после ответа API 202 с совпадающим ID и статусом accepted |
| `share` | Успех системного sharing или копирования ссылки |

Дополнительные параметры: `site_language`, `placement`, `form_id`, `error_type`, `method`. У заявки нет выдуманной денежной ценности. `generate_lead` отмечен в GA4 как ключевое событие, один раз на событие, без стоимости по умолчанию.

## Настройки веб-потока

Улучшенная статистика: оставлены загрузка страницы и прокрутка. Отключены изменения истории, исходящие клики, взаимодействия с формами, поиск, видео и скачивания. **Не включать автоматический сбор ссылок/форм:** WhatsApp URL может содержать данные заявки. Контактные события реализованы явно и не содержат `link_url`/`form_destination`.

Дополнительная редакция данных в GA4: email и URL-параметры `text`, `name`, `phone`, `note`, `email`, `comment`, `message`. Защита дублирует ограничения кода, но не заменяет их.

## Проверка

`npm run build:checked` проверяет отказ, согласие, отзыв, синхронизацию вкладок, блокировки, фильтрацию событий/URL и успешный приём заявок. После публикации открыть сайт, разрешить аналитику, воспользоваться кнопкой записи и начать форму. События смотреть в GA4 → Отчёты → В реальном времени. Не отправлять фиктивную заявку ради аналитики на рабочую почту. После отказа новая загрузка страницы не должна содержать Google script.
